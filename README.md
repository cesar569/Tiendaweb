# TiendaWeb

Aplicación web de tienda en línea desarrollada como parte de un proyecto académico de pruebas de software.

## Descripción

TiendaWeb permite al usuario consultar productos disponibles, agregarlos a un carrito de compras, modificar sus cantidades y realizar pedidos.

Entre las funcionalidades desarrolladas se encuentran:

- Consulta de productos.
- Visualización de nombre, precio, categoría y stock.
- Agregar productos al carrito.
- Incrementar la cantidad de productos.
- Disminuir la cantidad de productos.
- Eliminar productos del carrito.
- Cálculo del total de la compra.
- Registro de los datos del pedido.
- Validación de los datos del pedido.
- Confirmación del pedido.
- Generación del número de pedido.
- Vaciar el carrito después de confirmar un pedido.

## Pruebas de software

Como parte del proyecto se diseñaron y ejecutaron 30 casos de prueba en Azure DevOps.

Las pruebas abarcan funcionalidades relacionadas con:

- Productos.
- Carrito de compras.
- Control de stock.
- Cálculo del total.
- Registro y validación de datos.
- Confirmación de pedidos.
- Comportamiento del carrito después de confirmar un pedido.

Durante la ejecución se identificaron casos con resultado Passed y Failed. Los resultados y defectos encontrados fueron registrados en Azure DevOps.
